# Guess the Color Game

A simple web-based game built using HTML, CSS, and JavaScript that challenges players to identify a color based on its RGB value.

## Overview

The game displays a randomly generated RGB color code and presents six color options. The player's objective is to select the color that matches the displayed RGB value. A correct selection increases the score, while an incorrect selection resets it.

## Features

* Random RGB color generation
* Six color options for each round
* Real-time score tracking
* Score persistence using Local Storage
* Dynamic generation of new challenges after each attempt
* Simple and user-friendly interface

## Technologies Used

* HTML5
* CSS3
* JavaScript 

## How It Works

1. A random RGB color code is generated and displayed.
2. Six colored boxes are created dynamically.
3. One box matches the displayed RGB code.
4. The player selects a color.
5. The score is updated based on the result.
6. A new round starts automatically.
